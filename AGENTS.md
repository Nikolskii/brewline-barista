# AGENTS.md — brewline-barista

## Язык и роль

- Всегда отвечай по-русски.
- Это учебный проект: объясняй решения и их причины.
- React, TypeScript и HTTP автор знает хорошо; backend и инфраструктуру поясняй подробнее.

## Назначение и текущий инкремент

Интерфейс бариста для просмотра общей очереди и смены статусов заказов. Цель текущего инкремента: изменение статуса бариста синхронно обновляет и это приложение, и экран очереди. Создание заказов в скоуп не входит.

- Очередь использует тот же снапшот, что и display: `new`, `preparing` и свежие `ready`.
- Чтение очереди публичное; мутация статуса требует сессионную `httpOnly`-cookie с общим паролем смены.
- Frontend и API работают на разных origin: API-адрес приходит на этапе сборки через `VITE_API_URL`; Vite-proxy не использовать.

## Контракт и стек

- Типы API импортируй только из `@brewline/api-types`; не создавай их локальные копии.
- React, Vite, TypeScript strict, TanStack Query и SCSS Modules.
- Дизайн реализуй по утверждённому макету: светлая адаптивная раскладка, а не три одинаковые колонки.

## Безопасность

Не коммить `.env`, токены и пароли. Не клади секреты в `VITE_*`: они видны в браузерном бандле.
